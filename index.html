Firebase setup / required database rules

In Firebase Console → Realtime Database → Rules, publish the rules below. Also enable Authentication → Sign-in method → Anonymous. Build 0.8 uses Firebase REST requests. These room-creation rules are simpler than the previous version; after editing rules, press Publish and reload the site.

Prototype security note: these rules let any authenticated room member update signalling data. Don't use them unchanged for a public production app.


What is supported right now?
Create/join room, room code + invite link, device count, direct WebRTC file transfer (up to 50 MB), transfer progress, local and received audio, shared play/pause/seek commands, polling fallback, readable setup errors. Audio connection may still require a TURN relay on restrictive networks. Background playback and Apple Music streaming are not supported by this prototype.
